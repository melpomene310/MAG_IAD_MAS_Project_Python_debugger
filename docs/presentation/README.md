# Промежуточная презентация

Редактируемая версия для показа — `pilot_20261022.pptx`. В ней девять слайдов;
текст, таблицы и карточки трасс являются отдельными объектами PowerPoint.

Сводные цифры на слайдах 1, 2 и 4–9 взяты из полного пилота на 30 задачах:
`results/pilot30_live/20261022_{workflow,single_agent,mas_sequential}_dev_*`.
Это по 10 задач уровней easy, medium и hard. Каталог `results/` игнорируется Git,
поэтому перед презентацией он должен оставаться в локальной рабочей копии.

Карточки на слайде 7 — реальные сохранённые трассы раннего пилота на шести задачах,
из `tests/fixtures/run_outputs/english_pilot/`; их назначение — показать форму
взаимодействия ролей, а не представить выборку из 30 задач.

`pilot_20261022.html` — прежняя автономная версия для браузера и пока содержит
сводку раннего пилота; для показа используйте `.pptx`. Текст выступления Дмитрия
соответствует полному пилоту и находится в `speaker_notes.md`.
