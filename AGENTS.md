# AGENTS.md

LLM-система исправляет ошибки в Python-программах ConDefects; сравниваем workflow, одиночного агента и MAS. Введение — [README.md](README.md), полная спецификация — [docs/spec.md](docs/spec.md). При расхождении кода со спецификацией исправьте код или осознанно обновите спецификацию.

## Жёсткие правила

- Решатели не видят эталон: `solvers/`, `tools/`, `llm/`, `sandbox/` не используют `GroundTruth` и `ground_truth.json`. Это проверяет `tests/test_no_leakage.py` — не ослаблять.
- Чужой код запускается только через песочницу (`sandbox/`).
- Выборка `test` — только через `make final`. Промпты (только в `prompts/`) настраиваются на `dev`.
- Одинаковые условия для всех решателей: модель, параметры вызовов, лимиты, стартовая информация.
- Не коммитить `.env`, `data/`, `results/`, `.cache/`. Ключи не писать в код и чат.
- Изменения метрик (`eval/metrics.py`) — отдельным коммитом.

## Как работать

- Всё через `make`, внутри Docker.
- Прежде чем сказать «готово»: `make lint`, `make test`, `make smoke SOLVER=workflow` и `SOLVER=single_agent`. Не утверждайте, что работает, не запустив.
- Перечитайте свой diff: ошибки, лишние изменения, устаревшие комментарии.
- Новый код — с тестами; тесты не ходят в сеть (фейковая LLM, фикстуры).
- Запуски с реальной моделью стоят денег — сначала спросите.
- Поменяли поведение — обновите `docs/spec.md` и README.
